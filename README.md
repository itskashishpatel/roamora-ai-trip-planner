# 🌍 Roamora

### Find your kind of somewhere.

Roamora is an AI-powered trip planner that helps you discover destinations, create personalized itineraries, and organize your travel plans in one place.

## ✨ Features

- 🤖 AI-powered trip planning
- 🗺️ Destination discovery and inspiration
- ✈️ Personalized travel itineraries
- 💾 Save, resume, and manage trips
- 🔐 Secure user authentication
- 📱 Responsive user interface

## 🛠️ Tech Stack

**Next.js · React · TypeScript · Tailwind CSS · Clerk · Convex · OpenAI · Arcjet**

## 🚀 Getting Started

```bash
git clone https://github.com/itskashishpatel/roamora-ai-trip-planner.git
cd roamora-ai-trip-planner
npm install
npm run dev
```

Configure the required environment variables in `.env.local` before running the application.
